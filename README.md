
# Tienda Web — Proyecto Universitario

Proyecto de una tienda web de ropa desarrollado en el año 2024 con fines académicos. Su objetivo fue aprender y poner en práctica los fundamentos del desarrollo web utilizando **PHP, HTML y CSS**, además de familiarizarse con XAMPP para ejecutar y visualizar el proyecto en un entorno local.

## Objetivos del proyecto

- Aprender los fundamentos de PHP para el desarrollo web.
- Construir páginas web utilizando HTML y CSS.
- Comprender la estructura y organización de un proyecto web.
- Aprender a ejecutar aplicaciones PHP mediante un servidor local.
- Familiarizarse con XAMPP y Apache.
- Practicar la organización de archivos, imágenes y estilos de una tienda web.

## Tecnologías utilizadas

- **PHP:** programación del lado del servidor.
- **HTML5:** estructura y contenido de las páginas.
- **CSS3:** diseño y estilos de la interfaz.
- **XAMPP:** entorno de desarrollo local.
- **Apache:** servidor web para ejecutar el proyecto.

## Entorno de desarrollo

El proyecto se desarrolló y ejecutó localmente en Windows mediante XAMPP.

La carpeta del proyecto se ubicó en la siguiente ruta:

```text
C:\xampp\htdocs\Tienda
```

## Instalación y ejecución

1. Instalar [XAMPP](https://www.apachefriends.org/).
2. Clonar o descargar este repositorio.
3. Copiar los archivos del proyecto en la carpeta:

   `C:\xampp\htdocs\Tienda`

4. Abrir el panel de control de XAMPP.
5. Iniciar el servicio **Apache**.
6. Abrir el navegador y acceder a:

   `http://localhost/Tienda/`

> Si el proyecto utiliza una base de datos, también será necesario importar el archivo SQL correspondiente y configurar la conexión.
